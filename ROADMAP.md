# Roadmap

Topic order follows the [NeetCode roadmap](https://neetcode.io/roadmap). A topic is **unlocked** once you can
solve ~80% of the previous topic's core problems `clean`. A topic's folder is only created when that topic is unlocked.

Reviews never stop. Older topics keep showing up through `review.py`.

## System design (weekends)

1. [NeetCode: System Design for Beginners](https://neetcode.io/courses/system-design-for-beginners) (free)
2. [System Design Primer](https://github.com/donnemartin/system-design-primer) (free, deeper reference)
3. Practice designs in `system-design/`: URL shortener → rate limiter → chat app → news feed
4. Later: Alex Xu, *System Design Interview Vol. 1* / [ByteByteGo](https://bytebytego.com), and [Hello Interview](https://www.hellointerview.com/learn/system-design/in-a-hurry/introduction) for practice
